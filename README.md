# 림퀴즈

림버스 컴퍼니 콘텐츠(인격, 스킬, 덱, EGO, EGO 기프트)를 맞히는 웹 기반 퀴즈 모음입니다.

## 인격 데이터 수정 방법

`CharacterTable.xlsx` 파일만 편집하고 git에 push하면 됩니다.  
Vercel이 빌드 시 자동으로 `data.json`을 다시 생성해서 반영합니다.  
`index.html`을 직접 수정할 필요는 없습니다.

### 엑셀 파일 구조

- 파일명: `CharacterTable.xlsx`
- 시트: `CharacterData` (변환 대상)
- 컬럼: `수감자`, `인격명`, `성급`, `키워드1`, `키워드2`, `키워드3`
- 시트 `출처_메모`는 변환에서 제외됩니다.

## 로컬 개발

```bash
npm install
npm run build   # JSON 데이터와 로컬 파일용 local-data.js 생성
npx serve .     # 로컬 서버 실행 후 http://localhost:3000 접속
```

빌드 후에는 `index.html`을 직접 열어도 됩니다. 파일로 열면 같은 폴더의
`local-data.js`를 사용하므로, 엑셀 데이터를 수정한 뒤에는 빌드를 다시 실행하세요.

## 이미지 퀴즈

홈의 **관리자 식별 교육**에서 인물, 보스 아이콘, 패닉 유형 퀴즈로 이동합니다.
세 모드 모두 범위 선택 없이 전체 자료에서 바로 출제하며, 이름 검색/입력, 등장 위치 힌트,
중복 추측 방지, 정답 공개, 다음 문제, 새로고침 복원을 지원합니다.
등장 위치는 힌트를 누를 때 공개하며 사용 횟수에 포함됩니다. 위치가 확인되지 않은 항목은
힌트를 비활성화합니다. 패닉 퀴즈는 사기저하·패닉 효과도 순서대로 힌트로 공개합니다.
완료 기록은 기존 `limbus_results_v2`에 저장되어 홈의 필터·통계·백업에서 함께 관리됩니다.
검색 후보는 클릭 또는 방향키·Enter로 선택하고, ‘추측하기’ 또는 Enter로 제출합니다.
EGO·기프트 퀴즈와 같은 정보 패널, 추측·힌트 비용 표시, 이미지 포함 TRY 기록 카드를 사용합니다.
힌트 공개·정답·문제 전환 연출은 기존 `limbus_motion_pref` 설정을 공유합니다.

- `visualQuizData.json`: 배포용 정답·등장 기록·힌트·출처 데이터. 수정 후 `npm run build`로 반영합니다.
- `visualQuizCharacterReview.json`: 인물 엑셀의 이름 초안과 제외 목록. `x`·빈칸·`확인 필요`는 출제하지 않습니다. 과거·변형 표기가 붙은 이름은 기본 이름도 정답으로 인정합니다.
- `visualQuizBossReview.json`: 사용자 검수 보스 이름과 제외 목록. `x`로 표시한 13개 파일은 제외하고 39개 보스를 출제합니다. 원본 재수집 시에도 이 검수 결과를 우선합니다.
- `images/visual-quiz/`: 로컬 WebP 이미지. 드라이브 인증이나 외부 이미지 서버 없이 동작합니다.
- `visualQuizData.js`: `scripts/build-visual-quiz.js`의 생성 파일. `file://` 실행도 지원합니다.
- `visualQuizImageManifest.json`, `visualQuizSources.json`: 수집에 사용한 공개 이미지 메타데이터와 원문 파일 목록.
- `scripts/import-visual-quiz.js`: 명시적으로 실행하는 수집 도구. Drive 커넥터에서 받은
  `{id, url}` 다운로드 참조 목록을 `.codex-tmp/visual-downloads.json`에 준비해야 합니다.
  만료된 참조는 다시 발급받습니다. 이 도구는 배포 빌드에 포함되지 않습니다.

첫 수록분은 인물 24개, 보스 27개, 패닉 아이콘 86개입니다. 패닉에는 이름이 같은
서로 다른 아이콘이 있어 이름 기준으로는 85개입니다. 정확한 이름을 확인하지 못한
보스 이미지와 숫자 ID가 없는 공용 패닉 이미지는 제외했습니다.
등장 기록의 기본 인물은 0, 장별 항목은 1~10, 별도 콘텐츠는 11 이상으로 분류합니다.
구체적인 등장 위치는 선택적인 `location` 필드로 지정할 수 있습니다.
이전 버전의 범위별 진행 상태도 같은 문제와 추측 기록을 유지한 채 전체 출제로 이전됩니다.

`npm run check:visual-quiz`로 정답 판정, 위치 힌트, 중복 출제 방지, 이전 세션 복원과 이미지 경로를 검사합니다.
